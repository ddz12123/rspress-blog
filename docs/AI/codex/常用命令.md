# Codex Windows 常用命令

## 安装

```powershell
pip install openai-codex
```

或通过 npm：

```powershell
npm install -g @openai/codex
```

## 启动

```powershell
codex
```

在当前项目目录启动交互式终端：

```powershell
cd 项目路径
codex
```

## 常用模式

### 对话模式

```powershell
codex
```

进入交互式终端，直接输入问题或需求。

### 一次性命令

```powershell
codex "解释这个项目的目录结构"
codex "给这个函数写测试"
```

### 管道模式

```powershell
Get-Content error.log | codex "分析这些错误"
git diff | codex "帮我 review 代码改动"
```

## 实用命令

| 命令 | 作用 |
|------|------|
| `/help` | 查看帮助 |
| `/clear` | 清除当前对话 |
| `/reset` | 重置对话上下文 |
| `/cost` | 查看当前会话消耗 |
| `/status` | 查看当前状态 |
| `Ctrl+C` | 中断当前操作 |
| `Ctrl+D` | 退出 Codex |

## 环境变量

```powershell
# 设置代理
$env:HTTPS_PROXY="http://127.0.0.1:7890"
$env:HTTP_PROXY="http://127.0.0.1:7890"

# 指定模型
$env:CODEX_MODEL="gpt-5.5-codex"

# verbose 日志
$env:CODEX_VERBOSE=1
```

## 常用参数

```powershell
# 一次性执行
codex --prompt "写一个快速排序"

# 指定输出格式
codex --format json

# 不自动读取文件
codex --no-read

# 指定工作目录
codex --workdir "D:\projects\my-app"
```

## Windows 路径注意事项

- 路径含空格用双引号包裹
- 使用 `/` 替代 `\`，或 `\\` 转义
- 建议项目路径不要太深
