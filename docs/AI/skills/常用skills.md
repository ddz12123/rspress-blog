# 常用 Skills 网站

| 名称 | 网址 | 说明 |
| --- | --- | --- |
| **SkillsMP** | <https://skillsmp.com> | 最大的 Agent Skills 市场，124w+ 技能，支持 Claude Code、Codex CLI、ChatGPT，采用开放的 SKILL.md 标准，支持按职业分类浏览 |
| **ClawHub** | <https://clawhub.ai> | OpenClaw 官方技能市场，52k+ 工具，涵盖 Skills 和 Plugins，支持一键安装 |
| **Skills.sh** | <https://skills.sh> | 开放的 Agent Skills 生态，提供排行榜和搜索，`npx skills add` 一键安装，收录了 Microsoft、飞书等官方 skills |
| **SkillHub** | <https://skillhub.cn> | 专为中国用户优化的 Skills 社区，提供中文搜索和分类浏览 |
| **Cursor Directory** | <https://cursor.directory> | Cursor 编辑器社区 rules 目录，支持按技术栈（React、Next.js、Vue、Angular 等）筛选，.cursorrules 文件格式 |
| **awesome-cursorrules** | <https://github.com/PatrickJS/awesome-cursorrules> | 社区维护的 Cursor Rules 合集（GitHub），覆盖前端、后端、移动端、数据库等各领域，持续更新 |
| **Manus Agent Skills** | <https://manus.im/features/agent-skills> | Manus 平台的 Agent Skills 功能，支持在云端沙箱中一键执行 skills，内置 SimilarWeb、YahooFinance 等数据源 |
| **Awesome Manus** | <https://awesome.manus.space/?category=skills> | Manus 官方 skills 用例库，展示实际工作流场景 |
| **Superpowers** | <https://github.com/obra/superpowers> | 116k+ ⭐ 的 AI 编程方法论框架，涵盖 brainstorming → plan → TDD → code review 完整流程，支持 Claude Code、Cursor、Copilot CLI、Gemini CLI 等 |
| **Skill.market** | <https://skill.market> | 面向 Web3 领域的 AI agent skills 目录，支持分类浏览和提交 |
| **OpenAI Skills** | <https://github.com/openai/skills> | OpenAI 官方 AI 编程 skills 仓库，包含 CI 修复、PR 审查、前端设计、部署等常用技能 |
| **Claude Code Plugins** | <https://github.com/anthropics/claude-code/tree/main/plugins> | Anthropic 官方 Claude Code 插件仓库，包含 code-review、feature-dev、frontend-design、security-guidance 等 14 个官方插件 |
