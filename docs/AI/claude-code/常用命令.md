# Claude Code Windows 常用命令

## 安装

```powershell
npm install -g @anthropic-ai/claude-code
```

或通过 winget：

```powershell
winget install Anthropic.ClaudeCode
```

## 启动

```powershell
claude
```

当前目录启动（推荐，会自动识别项目上下文）：

```powershell
claude -p "你的项目路径"
```

## 常用模式

### 对话模式

```powershell
claude
```

进入交互式终端，直接输入问题或需求。

### 一次性命令

```powershell
claude -p "解释一下这个项目的架构"
claude -p "给 src/utils.ts 加单元测试"
```

### 管道模式

```powershell
cat error.log | claude -p "分析这些错误"
git diff | claude -p "帮我 review 这些改动"
```

## 实用命令

| 命令 | 作用 |
|------|------|
| `/help` | 查看帮助 |
| `/clear` | 清除当前对话 |
| `/reset` | 重置对话上下文 |
| `/cost` | 查看当前会话消耗 |
| `/doctor` | 诊断环境问题 |
| `Ctrl+C` | 中断当前操作 |
| `Ctrl+D` | 退出 Claude Code |

## 环境变量

```powershell
# 设置代理
$env:HTTPS_PROXY="http://127.0.0.1:7890"
$env:HTTP_PROXY="http://127.0.0.1:7890"

# 指定模型
$env:ANTHROPIC_MODEL="claude-sonnet-4-20250514"

# 最大思考预算
$env:CLAUDE_CODE_MAX_TOKENS=16000

# verbose 日志
$env:CLAUDE_CODE_VERBOSE=1
```

## Windows 路径注意事项

- 路径含空格用双引号包裹
- 使用 `/` 替代 `\`，或 `\\` 转义
- 项目路径建议不要太深（避免 Windows 路径长度限制）

## 常用参数

```powershell
# 指定输出格式
claude --output-format json

# 不自动读取文件
claude --no-read-file

# 允许自动执行命令
claude --allow-autonomous

# 指定日志级别
claude --verbose
```
