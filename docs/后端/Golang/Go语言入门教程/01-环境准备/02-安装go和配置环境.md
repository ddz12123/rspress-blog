# 安装 Go 和配置环境

Go 官方下载页：

```text
https://go.dev/dl/
```

进入页面后，下载适合你系统的安装包。

## 一、安装完成后检查

打开终端：

```bash
go version
```

如果看到类似输出，说明安装成功：

```text
go version go1.26.4 windows/amd64
```

具体版本号以你安装时 Go 官方下载页显示的稳定版为准。

## 二、查看 Go 环境

```bash
go env
```

常见字段：

| 字段 | 说明 |
|------|------|
| `GOROOT` | Go 安装目录 |
| `GOPATH` | Go 工作区和模块缓存默认位置 |
| `GOMOD` | 当前项目的 `go.mod` 路径 |
| `GOPROXY` | 下载依赖使用的代理 |

现在写项目主要看 `go.mod`，不是把代码放到 `GOPATH/src`。

## 三、配置依赖代理

国内网络环境下，可以设置 Go 代理：

```bash
go env -w GOPROXY=https://goproxy.cn,direct
```

查看：

```bash
go env GOPROXY
```

如果你所在网络能稳定访问官方代理，也可以使用默认配置。

## 四、推荐编辑器

推荐使用 VS Code，并安装官方 Go 扩展。

第一次打开 Go 文件时，VS Code 可能提示安装工具，比如：

- `gopls`
- `goimports`
- `dlv`

这些工具用于代码提示、格式化和调试，按提示安装即可。

## 五、格式化工具

Go 官方提供统一格式化工具：

```bash
gofmt -w .
```

Go 代码不需要争论缩进和括号风格，保存时自动格式化即可。
