# 安装、启动和连接

这一节记录本地启动 Redis 和连接方式。

## 一、Docker 启动 Redis

本地练习最方便的是 Docker：

```bash
docker run --name redis-tutorial -p 6379:6379 -d redis:7
```

查看容器：

```bash
docker ps
```

进入 Redis CLI：

```bash
docker exec -it redis-tutorial redis-cli
```

停止：

```bash
docker stop redis-tutorial
```

再次启动：

```bash
docker start redis-tutorial
```

删除：

```bash
docker rm -f redis-tutorial
```

## 二、连接 Redis

本机连接：

```bash
redis-cli
```

指定地址和端口：

```bash
redis-cli -h 127.0.0.1 -p 6379
```

连接成功后执行：

```text
PING
```

返回：

```text
PONG
```

表示连接正常。

## 三、基本读写

```text
SET name Tom
GET name
```

返回：

```text
"Tom"
```

删除：

```text
DEL name
```

再次查询：

```text
GET name
```

返回：

```text
(nil)
```

`(nil)` 表示 key 不存在。

## 四、设置过期时间

设置 key，并让它 60 秒后过期：

```text
SET verify:code:1001 9527 EX 60
```

查看剩余时间：

```text
TTL verify:code:1001
```

也可以先设置，再单独加过期时间：

```text
SET token:abc user-1
EXPIRE token:abc 3600
```

## 五、选择数据库

Redis 默认有多个逻辑数据库，编号从 0 开始。

```text
SELECT 0
SELECT 1
```

本地练习可以使用默认的 `0`。

项目里更推荐通过 key 前缀区分业务，而不是依赖多个逻辑数据库隔离业务。

## 六、清理数据

删除当前数据库所有 key：

```text
FLUSHDB
```

删除所有数据库所有 key：

```text
FLUSHALL
```

这两个命令非常危险，只适合本地练习环境。

## 七、查看服务信息

查看服务器信息：

```text
INFO
```

只看内存：

```text
INFO memory
```

只看客户端：

```text
INFO clients
```

查看当前数据库 key 数量：

```text
DBSIZE
```
